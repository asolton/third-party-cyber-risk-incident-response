Third-Party Cybersecurity Risk & Incident Response Assessment

## Project Overview

This project simulates a third-party cybersecurity risk assessment performed for a critical technology vendor supporting a large enterprise organization.

The assessment demonstrates the process of evaluating vendor security controls, identifying cybersecurity risks, prioritizing findings, and developing remediation recommendations.

A simulated security incident is also investigated using incident response methodologies, MITRE ATT&CK, and the Cyber Kill Chain.

## Vendor Profile

**Vendor:** NorthStar Cloud Solutions

**Industry:** Cloud Technology / SaaS

**Service Provided:** Cloud-based enterprise data and workflow platform

**Vendor Classification:** Critical Third Party

**Data Access:** Business and customer information

**Environment Access:** Privileged administrative access to designated enterprise systems

## Assessment Objective

The objective of this assessment is to:

- Evaluate the vendor's cybersecurity controls
- Identify security gaps and vulnerabilities
- Assess the potential business impact of identified risks
- Prioritize findings based on likelihood and impact
- Develop practical remediation recommendations
- Determine whether the vendor should be approved, conditionally approved, or rejected
- Demonstrate the incident response process following a simulated security event

## Assessment Frameworks

The assessment incorporates concepts from:

- NIST Cybersecurity Framework
- NIST Incident Response
- MITRE ATT&CK Enterprise
- Cyber Kill Chain
- SOC 2
- ISO/IEC 27001

## Disclaimer

This is a simulated cybersecurity portfolio project. All organizations, vendors, data, security findings, and incidents are fictional and created for educational and demonstration purposes.
