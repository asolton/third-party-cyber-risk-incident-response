## Overview

A simulated cybersecurity project focused on third-party risk assessment, incident response, and SOC investigation.

The project evaluates vendor security-control weaknesses, prioritizes risks, maps simulated attack activity to MITRE ATT&CK Enterprise and the Cyber Kill Chain, and investigates a simulated incident using authentication, endpoint, and network telemetry.

## Key Findings

* Identified critical risks involving privileged accounts without MFA, vulnerability-management gaps, third-party security assessments, and incident communication.
* Prioritized risks using likelihood and impact scoring.
* Mapped simulated attacker behavior to MITRE ATT&CK and the Cyber Kill Chain.
* Correlated authentication, endpoint, and network telemetry to investigate suspicious privileged-account activity.
* Recommended containment, evidence preservation, and escalation to incident response.

## SOC Investigation

The simulated investigation included:

* Authentication logs

* Incident timeline development
